# Phases

## Phase 0
- FastAPI backend, SQLAlchemy, Alembic, Postgres, pgvector, Redis, Vite, Tailwind, and shared entity CRUD
- Unified capture form
- Entity list and detail views

## Phase 1
- DSA tracker
- Project hierarchy with parent-child task structure
- Subject tracker
- Today dashboard
- Task-to-TIL flow

## Phase 2
- Embedding generation and refresh
- Similar entity search
- Link candidate suggestions from embeddings
- Confirmed-links graph view in Cytoscape
- Confidence decay and revisit flows

## Phase 3
- AI provider abstraction
- Prompt organization and JSON schema helpers
- Duplicate detector scaffolding
- Deep connection agent scaffolding
- Daily guidance
- Safe disabled-mode behavior

## Phase 4
- BlockNote note support
- Excalidraw canvas support
- GitHub webhook ingestion
- PR-to-TIL draft flow
- Comprehension checks and AI-assist debt surfaces

## Phase 5
- Weekly digest
- Tag taxonomy and coverage gaps
- Shipping vs learning analytics
- CI status dashboard from GitHub sessions
- Weekly analyst brief with deterministic fallback and optional AI summarization

## Project Tracker V2
- Portfolio view with search, status and health filters, delivery KPIs, and inline project creation
- Computed project health, progress, deadlines, stalled-work detection, and Today attention signals
- Project workspace with overview, Kanban board, milestone timeline, delivery activity, knowledge, and settings
- Rich project, milestone, and task metadata with validated statuses, priorities, dates, estimates, outcomes, and acceptance criteria
- Cross-task dependency links, WIP warnings, drag-and-drop status changes, and task work logs
- Required task-completion learning checkpoint with linked TIL capture and AI comprehension checks
